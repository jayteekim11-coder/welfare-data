지원금나침반 개인정보처리방침

시행일: 2026년 11월 3일

1. 한눈에 보기

  • 지원금나침반은 회원가입이 없고, 입력한 정보를 개발자 서버로 보내지 않아요.
  • 사는 곳·생년월·성별·상황·적은 내용·관심 혜택은 사용자의 휴대폰 안에만 저장돼요.
  • 앱을 지우면 저장된 정보도 모두 지워져요.
  • 지원금나침반은 개인이 만든 앱으로, 정부·지방자치단체·공공기관과 관련이 없어요.

2. 휴대폰 안에만 저장하는 정보

  • 프로필: 사는 지역(시·도, 시·군·구), 태어난 해와 달, 성별, 선택한 소득 구간과 상황(예: 임신, 장애, 한부모)
  • 가족 프로필: 사용자가 추가한 가족의 같은 항목
  • 서술형으로 적은 내용, 관심 혜택과 신청 상태, 최근 본 혜택, 구비서류 체크 표시, 앱 설정

이 정보는 혜택을 골라 보여주고 알림을 보내는 데에만 쓰이며, 외부로 전송되지 않아요.

3. 인터넷으로 받는 정보

앱은 공공데이터(행정안전부 「대한민국 공공서비스(혜택) 정보」)를 정리한 파일을 GitHub Pages에서 내려받아요. 이때 사용자의 정보는 함께 보내지 않아요. 다만 인터넷 통신의 특성상 GitHub이 접속 기록(IP 주소 등)을 남길 수 있어요.

4. 광고

앱에는 Google AdMob 광고가 표시돼요. Google은 광고를 보여주고 성과를 측정하기 위해 광고 ID 등 기기 정보를 수집할 수 있어요. 자세한 내용은 Google 광고 정책을 확인해 주세요. 휴대폰 설정 → Google → 광고에서 맞춤 광고를 끌 수 있어요.

5. 오류 보고

앱이 비정상 종료되면 오류 내용을 휴대폰에만 기록해요. 다음 실행 때 사용자가 직접 보내기를 선택한 경우에만 메일 앱으로 개발자에게 전달돼요. 보내지 않으면 외부로 나가지 않아요.

6. 권한

  • 인터넷: 혜택 정보를 받기 위해 필요해요.
  • 알림(선택): 관심 혜택 마감·새 혜택 알림을 보내기 위해 필요해요.
  • 음성 입력(선택): 마이크 버튼을 누를 때 휴대폰의 음성 인식 기능을 사용해요. 녹음은 앱에 저장되지 않아요.
